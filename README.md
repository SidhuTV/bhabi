# Bhabi — Web Card Game (starter)

This is a minimal browser-based starter for a card game named "Bhabi". It currently implements a simple single-player vs computer trick-taking mechanic:

- Standard 52-card deck
- Deal 5 cards each
- Each round: player selects a card, computer plays a card (random AI), higher rank wins the trick
- Score tracked across the hand

Files:
- `index.html` — UI
- `style.css` — basic styling
- `app.js` — game logic and UI interaction

How to run:
1. Place all files in a directory.
2. Open `index.html` in a browser (or run a static server).
